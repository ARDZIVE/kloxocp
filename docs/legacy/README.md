# Legacy notes

The CentOS/RHEL installer and RPM/yum helpers that used to live under
`kloxo/install/` and various `pscript/` scripts have been **removed**.

Kloxo CP targets **Ubuntu 24.04 and Ubuntu 26.x** only. Install with:

```bash
curl -fsSL https://raw.githubusercontent.com/ARDZIVE/kloxocp/main/get | sudo bash
```

Do not follow old Kloxo-MR CentOS `yum install kloxo` instructions.
