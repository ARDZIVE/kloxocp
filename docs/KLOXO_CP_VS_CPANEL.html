Overall rating — utility & security

Overall = weighted blend of utility (60%) and security (40%). Utility averages all categories with extra weight on web/apps, mail UX, backup/transfers, reseller, API. Security averages mail security design, firewall/brute-force, recovery, watchdog, core hygiene, WAF/suites, panel DB resilience.

Kloxo CP — overall

5.8 / 10

Utility: 5.4 · Security: 6.4 (was 5.5 / 5.0 / 6.3)

  • Latest lift: kloxocp upcp (cPanel-style) with snapshot, health check, and automatic rollback — php-cli tested.
  • Also recent: curl …/get | sudo bash, CentOS removal, Backup Now, Aux login, default_plan, SMTP overlay, UI toasts.
  • Utility still held down by apps, transfers, mail UI (P4), public API, signed apt, and production readiness.
  • Still not recommended as a public cPanel/Hestia/ISPConfig replacement today.

cPanel / WHM — overall

8.8 / 10

Utility: 9.1 · Security: 8.3

  • Clear winner for paid shared hosting, WordPress-centric customers, Softaculous/WP Toolkit, Transfer Tool, and vendor support.
  • Security is strong via ecosystem (cPHulk, ModSecurity, Imunify) even if panel DB outage recovery is weaker than Kloxo’s design.
  • Cost and closed source are the main trade-offs vs Kloxo.
  • Recommended choice for production hosting today.
